# 轴④ 定向造饵（model-failure-baited decoys）

**加的是什么难度**：诱饵不是"编得像"，而是**标尺模型在当前版本上真实犯过的错** —— 它自己写出的错值就是"最像对的错值"。这是唯一一条**闭环**的轴：跑 → 收集失败 → 造饵 → 再跑。

## 0. 前置条件（不满足就别启动这一轴）

- **必须有失败样本**：至少有一批 run（同一题、同标尺模型、同预算）出现过 `score < 1.0`。
- 没有失败样本时：要么先做轴①②③把题推过模型的能力线，要么**换一个更弱的标尺模型**产生失败样本。
  注意：**难度是相对标尺的** —— 换标尺必须在报告里写清楚，且不同标尺的曲线不可比。
- 只用**内部跑批**的失败样本（不得使用公开榜单的题解、不得使用测试集外的答案）。

## 1. 一眼假 vs 真实难度（硬对照）

| 维度 | ✗ 一眼假（禁止） | ✓ 定向造饵（要求） |
| --- | --- | --- |
| 诱饵来源 | 凭空编一个"看起来像"的错值 | **从失败 run 里原样取**：模型实际写出的值与理由 |
| 分布匹配 | 不在模型的错误分布里（它从没这么错过） | 就是它**真的会犯**的错（同模型、同 harness、同预算） |
| 标注 | 无来源 | 每条饵必须标注 `from_run` / `wrong_value` / `failure_type` |
| 时效 | 一直用同一批饵 | 模型不再踩 → 换新的失败模式（饵会过期） |
| 效力度量 | 不看效果 | 度量**同错误命中率**：下一轮有多少 run 踩了该饵 |

**一句话检验**：这条诱饵能不能指到一个真实的失败 run 的具体错误？指不到 → 不是定向造饵。

## 2. 手法

1. **收集**：从跑批 db 里取失败 run 的产物与轨迹（`task_output` / `agent_output` / 判分 checks 的 `detail`），定位**错在哪一项检查**。
2. **归类失败类型**：版本判定错 / 权威选错 / 观测遗漏 / 取舍错 / 格式误读 —— 只对"判定类"失败造饵（"没做完"类的失败不造饵，那是预算问题）。
3. **物化**：把错值/错路径做成**工区里的一条真实材料**（同类别措辞、无免责句、日期晚于真相），并保证：
   - 它**不携带**任何自否定标记（见轴① 的对照表）；
   - 它与正本的差异**只能**靠另一条面（或另一族证据）来反驳。
4. **迭代**：再跑同口径 → 若该饵被踩（同错误命中率 > 0）保留；命中率为 0 → 该饵失效，换下一类失败模式。

## 2.5 决定性判定点（R4 起强制，≥3 个）

R3 实测教训：只把"模型写过的错值"放进新文件不够 —— 模型在新环境里未必再走到那一步。**诱饵必须挂在判定路径上：模型只要按默认路径走（照抄最显眼的那份、按通用规则办），就必然产出该错值，并且这个错值必须是判分项。**

- 每条饵 → 一个判定点 → 一个 `scored_check`；
- 用**同一批已失败的 checks** 反查：R2/R3 的失败集里，`case:C21`（nature 写 11）、`case:C34`（mode 写 1）、`case:C3`（该缺报的报了）就是现成的、跨模型复现的饵锚点 —— 新变体要新增同类锚点（≥3 个），而不是重放旧锚点；
- 写进 `plan.yaml` 的 `decisive_points:`，`default_answer` = 该饵的错值，`attractor_location` = 饵的落点。

## 3. 产出要求（写进 `plan.yaml`）

```yaml
axis: targeted_decoys
baits:
  - from_run: <run_id>
    wrong_value: <模型当时写出的错值>
    failure_type: version_judgment|authority_selection|observation|tradeoff
    materialized_as: <工区路径>
    refutation_surface: <反驳它必须查的那条面>
    measure: {hit_rate_prev: null, hit_rate_next: null}
```

## 4. 自检（必须全过）

1. **来源可追**：每条饵都能指到一个具体失败 run 与其错值（写进 plan.yaml）。
2. **不自否定**：饵本身不含 "superseded / 仅供参考 / indicative" 等字眼（否则它退化成一眼假）。
3. **跨面可反驳**：见轴① 的单面截断测试 —— 只看工区应当判错。
4. **命中率被度量**：下一轮跑批后统计"有多少 run 踩了该饵、失败是否集中在对应检查"。
5. **失效即换**：命中率为 0 或失败类型转为"没做完"时，本饵作废、换模式（并记录）。

## 5. 与主 skill 的关系
